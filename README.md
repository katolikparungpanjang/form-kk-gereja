## 🙏 Selamat Datang

Formulir ini digunakan untuk **pendataan Kartu Keluarga umat** di Stasi Santo Laurensius Parung Panjang. Mohon bantuan Bapak/Ibu/Saudara untuk mengisi data keluarga dengan lengkap dan benar.

## 📝 Isi Formulir di Sini

👉 **[KLIK DI SINI UNTUK MENGISI FORMULIR](https://katolikparungpanjang.github.io/form-kk-gereja/)**

Atau salin tautan berikut ke browser HP/laptop Anda:
```
https://katolikparungpanjang.github.io/form-kk-gereja/
```

## 📋 Yang Perlu Disiapkan

Sebelum mengisi, mohon siapkan dokumen berikut agar data lebih akurat:

- Kartu Keluarga (KK) / KTP kepala keluarga & anggota
- Akta nikah gereja & akta nikah sipil (bila sudah menikah)
- Surat baptis, surat komuni pertama, surat penguatan (bila ada)

## 🪜 Cara Mengisi

1. Buka tautan formulir di atas
2. Isi data secara **bertahap**, mulai dari **Data Kepala Keluarga**
3. Lengkapi bagian **Biodata**, **Sakramen** (bila beragama Katolik), dan **Informasi Tambahan**
4. Tambahkan **Anggota Keluarga** bila ada (tekan tombol "➕ Tambah Anggota Keluarga")
5. Periksa kembali data di halaman **Ringkasan**
6. (Opsional) Centang bila ingin menerima **salinan data ke email** Anda
7. Klik **Kirim** — selesai! 🎉

## ❓ Tips & Bantuan

- **Field bertanda `*`** wajib diisi.
- Data **Nama, Jenis Kelamin, Tanggal Lahir** di bagian Biodata terisi otomatis dari langkah pertama.
- Jika halaman **tidak terbuka di HP**, coba buka lewat **Google Chrome** atau **Safari** secara langsung.
- Data Anda **aman** — hanya digunakan untuk keperluan pendataan gereja.
